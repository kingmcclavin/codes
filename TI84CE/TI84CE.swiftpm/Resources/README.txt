Optional: put your TI-84 Plus CE ROM dump in this folder (e.g. ti84ce.rom).

The app looks for any *.rom file here. If none is bundled, the app asks you to
import one with the Files picker instead, and keeps a private copy.

ROM images are copyrighted by Texas Instruments. Use a dump of a calculator you
own, and never commit it to a public repository (*.rom is git-ignored).
